# Ryft

> A modern compiled systems programming language for high-performance, scientific, and numerical computing.

Ryft is a statically typed, ahead-of-time compiled programming language focused on predictable performance, explicit control, and modern language design. It is intended for systems programming, scientific computing, numerical simulation, and other performance-critical applications.

## Features

- Ahead-of-time (AOT) compilation
- Strong static typing
- Zero runtime overhead
- Explicit memory management
- Modular compilation system
- Traits and implementations (`trait` / `impl`)
- Structures, unions, and enumerations
- First-class multidimensional arrays
- Matrix and element-wise operators
- User-defined type and memory attributes
- Optional function arguments
- Modern and expressive syntax
